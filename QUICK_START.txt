================================================================================
TROUBLESHOOTING
================================================================================

Q: "Cannot find module 'express'"
A: Run: npm install

Q: "Port 3000 is already in use"
A: Edit .env, change PORT=3000 to PORT=3001

Q: "Maps not loading"
A: Check internet connection, allow location permission

Q: "Cannot login"
A: Ensure user exists, try different email/password

Q: "Database error"
A: Delete ev_charging.db file, restart server

Q: Database file location?
A: Automatically created in same folder as server.js

================================================================================
DATABASE STRUCTURE
================================================================================

4 Main Tables:

1. users
   - ID, email, password, role (admin/user), created_at

2. bunks
   - ID, name, address, mobile, total_slots, available_slots, lat, lng

3. bookings
   - ID, user_id, bunk_id, booking_date, booking_time, status

4. password_resets
   - ID, user_id, token, expires_at

Auto-created on first server start!

================================================================================
API ENDPOINTS
================================================================================

Authentication:
  POST /api/auth/register
  POST /api/auth/login
  POST /api/auth/forgot-password

Bunks:
  GET  /api/bunks
  POST /api/bunks (admin)

Bookings:
  GET  /api/bookings
  POST /api/bookings
  DELETE /api/bookings/:id

Admin:
  GET /api/bunks/:id/slots (admin)
  PUT /api/bunks/:id (admin)
