⚙️ FIRST TIME SETUP:
────────────────────────────────────────────────────────────────────────────────

   STEP 1: Start Server
   ─────────────────
   npm start
   (Opens on http://localhost:3000 automatically)


   STEP 2: Create User Account
   ─────────────────────────
   1. Go to: http://localhost:3000/index.html
   2. Click "Register"
   3. Enter: Email and Password
   4. Click "Register"


   STEP 3: Create Admin Account
   ──────────────────────────
   1. Open NEW terminal (keep server running)
   2. Type: node setup-admin.js
   3. Enter admin email: admin@test.com
   4. Enter admin password: admin123456
   5. Done!


   STEP 4: Add Charging Station
   ──────────────────────────
   1. Go to: http://localhost:3000/admin.html
   2. Login with admin credentials
   3. Fill: Name, Address, Mobile, Slots
   4. Click "Save Bunk"
   5. See it on map!


   STEP 5: Book a Slot
   ─────────────────
   1. Go to: http://localhost:3000/index.html
   2. Login with user account
   3. Click "Book Slots"
   4. Select station
   5. Choose date and time
   6. Click "Confirm Booking"
   7. Done! 🎉

🔧 TROUBLESHOOTING:
────────────────────────────────────────────────────────────────────────────────

   Q: "Cannot find module"
   A: npm install


   Q: "Port 3000 in use"
   A: Edit .env → Change PORT to 3001


   Q: "Maps not loading"
   A: Check internet, allow location permission


   Q: "Cannot login"
   A: Create account first, check email/password


   Q: "Database error"
   A: Delete ev_charging.db, restart server


   See QUICK_START.txt for more help!
